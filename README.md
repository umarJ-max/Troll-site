# 🎭 Troll Site

> A fun interactive website that trolls users with a moving "Yes" button and personalized messages. Perfect for pranking friends!

![Mobile](https://img.shields.io/badge/mobile-friendly-brightgreen.svg)

---

## ✨ Features

- Personalized welcome screen — asks for the user's name before starting
- A troll question appears with their name in it
- One button runs away when hovered or tapped — the user can never click it
- The other button reveals the punchline message
- Confetti fires on the reveal
- Name protection — certain names are blocked from being entered
- Admin can customize the question, which button runs, and the reveal message
- All settings persist across sessions via localStorage
- Fully responsive — works on mobile and desktop

---

## 🔧 Admin Panel

**Two ways to open it:**

1. On the welcome screen, type `hackAdm8` in the name field and hit Start
2. On desktop: press `Ctrl + Alt + Q`

**What you can change inside:**

- The troll question shown to the user (name is auto-added as "Hey [name],")
- Which button runs away — YES or NO
- The reveal message shown when the user finally clicks the stationary button

Changes save instantly and persist across page refreshes.
